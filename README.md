# fly-cord-robots

Driving a simulated legged robot with a real fruit fly (*Drosophila*)
ventral nerve cord connectome — the fly's spinal-cord equivalent — instead
of a hand-designed controller. Made for a YouTube video: a real hexapod
walking rhythm, generated by real fly wiring, tested on a robot body it
never evolved for (a hexapod, then an "amputated" quadruped).

Full project context, honesty constraints, and the phase roadmap live in
[`CLAUDE.md`](CLAUDE.md) — read that first if you're picking this up.
Dated findings (what we tried, what worked, what didn't, and why) are in
[`CHANGELOG.md`](CHANGELOG.md), which indexes into
[`docs/logs/`](docs/logs/).

## Setup

```bash
python3.12 -m venv .venv   # 3.12, not the system's latest — better wheel
source .venv/bin/activate  # compatibility with the scientific-stack deps below
pip install -r requirements.txt
```

You'll also need a neuprint auth token (for querying the MaleCNS
connectome) — get one from https://neuprint.janelia.org (profile → Account
→ Auth Token) and put it in a `.env` file at the repo root:

```
NEUPRINT_TOKEN=your-token-here
```

To run Pugliese et al.'s own simulation code (used to validate the
biology — see `fly_robot/neural/`), also clone their repo and install our
config additions:

```bash
git clone https://github.com/smpuglie/Pugliese_cpg_2025.git external/Pugliese_cpg_2025
python -m fly_robot.neural.setup_pugliese_configs
```
